Exercise 2

Debug the Layout

Without box-sizing: border-box, padding is added on top of the width — making the box 340px instead of 300px.

✗ Broken — renders at 340px

width: 300px
padding: 20px
/* actual: 300 + 20 + 20 = 340px */

Default box-sizing is content-box. Padding is added outside the declared width.

✓ Fixed — renders at 300px

width: 300px
padding: 20px
box-sizing: border-box ← fix

border-box makes padding and border count inside the declared width. Total stays 300px.
